Build 21: faster SMB/NAS access with the new Rust engine.

SMB connections now use the Rust engine by default ("Auto (Rust, recommended)" in the connection dialog). Please test with your own NAS:
- Add or reopen an SMB library, browse folders (including names with spaces, umlauts or #), import a book and play it while it downloads.
- Large downloads: check speed, progress and that pausing/resuming or losing Wi-Fi mid-download completes correctly afterwards.
- Your NAS must allow SMB3; encryption is required by default. If your server has no encryption, the connection is refused unless you untick "Require SMB3 encryption".
- If anything fails, switch the connection's SMB transport to "libsmb2 (legacy)" and tell us whether that works.

Also in this build: everything from build 20 (Return Trail, listening journal, optional speed processors). Requires iOS 15 or newer.
