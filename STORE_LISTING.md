## Long description
CrisperPlayer is a versatile offline audiobook player for Android & iOS (Flutter, like CrisperWeaver). Native decoders handle m4b/m4a (Nero chpl chapters) + cover art, plus mp3/flac/ogg/wav/aac/opus/wma/aiff. Features: library sort/filter, resume from last position, listening history grouped by day, manual + auto bookmarks, sleep timer (including end-of-chapter), smart rewind, speed control, export/import JSON, onboarding, background playback.
