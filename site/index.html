        Local listening, with room to grow.

        The browser player supports local files, multiple tracks, speed control, resume and bookmarks.         Privacy

        This browser player stores audio, progress and bookmarks in this browser's IndexedDB. It does not upload audio or send listening analytics. GitHub Pages serves the site and may keep normal hosting logs.

        Licenses and source

        CrisperPlayer is licensed under GNU AGPL-3.0. The browser player uses browser APIs with no third-party JavaScript libraries. Native app dependency licenses and bundled codec/storage notices are available in Settings → About CrisperPlayer → View licenses and in each release archive.
