Build 20: Return Trail, listening journal and optional speed processing.

Return Trail: after skipping or seeking away, use Return Trail from the player to replay recently played passages. Check that it never overwrites your saved position, that lock-screen/headset controls keep working during a trail, and that the played-sections view and gap navigation match what you actually listened to.

Listening journal: open the journal, jump between dates, open a passage to start playback there, and export a filtered report. Check backups include the journal.

Speed processing: in playback settings, try the optional speed processors at 0.75x, 1.5x and 2x. Listen for artifacts, check that chapter positions, seeking and resume stay exact, and that switching back to the default restores normal playback.

SMB: re-check an existing SMB library and a new connection with saved settings; libsmb2 remains the default backend.

Regression checks: local M4B/multi-track imports, chapters, bookmarks, sleep timer, queue, waveform, background playback and interruptions (calls, other audio apps). Requires iOS 15 or newer.
