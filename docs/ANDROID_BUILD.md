## Prerequisites

- Flutter 3.44.1 (stable) — `flutter --version` should match `pubspec.yaml` (`>=3.24.0`).
- Android SDK + Platform Tools + Build-Tools. Install via Android Studio or `cmdline-tools`:
  ```bash
  # Ubuntu example
  mkdir -p ~/Android/Sdk/cmdline-tools
  # download https://developer.android.com/studio#command-tools -> cmdline-tools/latest
  unzip commandlinetools-linux-*.zip -d ~/Android/Sdk/cmdline-tools
  mv ~/Android/Sdk/cmdline-tools/cmdline-tools ~/Android/Sdk/cmdline-tools/latest
  sdkmanager --install "platform-tools" "platforms;android-34" "build-tools;34.0.0"
  sdkmanager --licenses  # accept
  ```
- Env:
  ```bash
  export ANDROID_HOME="$HOME/Android/Sdk"
  export PATH="$ANDROID_HOME/platform-tools:$ANDROID_HOME/cmdline-tools/latest/bin:$PATH"
  flutter config --android-sdk "$ANDROID_HOME"
  flutter doctor -v  # Android toolchain should be [✓]
  ```
- `android/local.properties` must contain `flutter.sdk=/path/to/flutter` (generated by `flutter pub get` / `flutter build`).

## Signing config

`android/app/build.gradle.kts` release currently uses debug keys so `flutter run --release` and local APK builds work without a keystore:

```kotlin
buildTypes {
    release {
        signingConfig = signingConfigs.getByName("debug")
    }
}
```

Verified: `signingConfig = signingConfigs.getByName("debug")`.

For Play Store release, replace with a `release` signingConfig backed by `android/key.properties` + `android/app/upload-keystore.jks` (do **not** commit the keystore):

```kotlin
// android/app/build.gradle.kts — add above android { }
val keystoreProps = java.util.Properties().apply {
    val f = rootProject.file("key.properties")
    if (f.exists()) load(java.io.FileInputStream(f))
}
android {
    signingConfigs {
        create("release") {
            val v = { k: String -> keystoreProps.getProperty(k) as String? }
            storeFile = v("storeFile")?.let { file(it) }
            storePassword = v("storePassword")
            keyAlias = v("keyAlias")
            keyPassword = v("keyPassword")
        }
    }
    buildTypes {
        release {
            signingConfig = signingConfigs.getByName("release")
            isMinifyEnabled = true
            isShrinkResources = true
        }
    }
}
```

```properties
# android/key.properties (gitignored)
storeFile=/path/to/upload-keystore.jks
storePassword=...
keyAlias=upload
keyPassword=...
```

Generate once: `keytool -genkey -v -keystore upload-keystore.jks -alias upload -keyalg RSA -keysize 2048 -validity 10000`.

## Build

From repo root (`/mnt/volume1/code/crisperplayer`):

```bash
flutter pub get
dart run build_runner build --delete-conflicting-outputs
nice -n 10 flutter build apk --release
# or split ABIs (smaller):
nice -n 10 flutter build apk --release --split-per-abi
# App Bundle for Play:
nice -n 10 flutter build appbundle --release
```

Outputs:
- `build/app/outputs/flutter-apk/app-release.apk`
- `build/app/outputs/flutter-apk/app-armeabi-v7a-release.apk` etc. with `--split-per-abi`
- `build/app/outputs/bundle/release/app-release.aab`

Helper scripts (no `ANDROID_HOME` guard in `build_all.sh` — it skips APK):

```bash
./build_android.sh        # -> flutter build apk --release
./build_all.sh            # pub get + build_runner + web + apk (if ANDROID_HOME set)
```

## CI

GitHub Actions example (`.github/workflows/android.yml`):

```yaml
jobs:
  android:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-java@v4
        with: { distribution: temurin, java-version: "17" }
      - uses: subosito/flutter-action@v2
        with: { channel: stable }
      - run: flutter pub get
      - run: dart run build_runner build --delete-conflicting-outputs
      - run: flutter build apk --release
      - uses: actions/upload-artifact@v4
        with: { name: apk-release, path: build/app/outputs/flutter-apk/app-release.apk }
```

## Troubleshooting

- `No Android SDK found` → set `ANDROID_HOME` and `flutter config --android-sdk`.
- `Unable to locate Android SDK` in `flutter doctor` → `sdkmanager --install` + accept licenses.
- `local.properties` missing `flutter.sdk` → rerun `flutter pub get`; never hand-edit beyond SDK path.
- Play Console rejects debug-signed APK → switch `buildTypes.release.signingConfig` to `release` as above.
