## Screenshot best practices

- **Use real data** — populate with 3–5 audiobooks so the library grid looks natural
- **Show progress** — partially-read books demonstrate the progress feature
- **Dark mode** — include at least one dark-mode screenshot (settings or player)
- **No personal data** — avoid real names, book titles with personal meaning
- **JPEG or PNG** — Play Store accepts both; App Store requires PNG
- **No frames** — don't add device bezels or marketing text overlays
- **Consistent device** — use the same device frame across all screenshots for a given size class
